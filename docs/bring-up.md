# Сборка, прошивка и первое включение

Это первый инженерный прототип, не проверенный в железе. Плата питается от
USB-хоста через кабель с линиями данных. От простой зарядки основной узел
автоматически не запускается. Уровни GPIO/UART — 5 В TTL, не RS-232 и не
гарантированно безопасные для 3,3-вольтовой периферии.

## Что подготовить

- Детали из BOM, включая точную THT-панель Preci-Dip и две DIP-панели.
  U4 именно **AS6C62256A-70PCN**; вариант без A не утверждён как замена.
- Мультиметр, желательно лабораторный USB-источник с ограничением тока или
  защищённый питаемый USB-хаб, осциллограф с щупом ×10 для диагностики.
- USB-C data-кабель, компьютер, драйвер FTDI VCP и утилиту FT_PROG.
- Внешний программатор, в списке поддерживаемых устройств которого явно
  есть **SST39SF010A** в PDIP32. Поддержка только «SPI Flash» не подходит:
  это параллельная 5-вольтовая Flash. Проверить поддержку конкретной версии
  ПО/программатора перед покупкой. USB-UART на плате её не заменяет.
- Съёмник PLCC, средство аккуратного извлечения DIP. Не тянуть за один угол.

## Порядок сборки

1. Проверить плату на замыкания, качество маски и сверления. Сопоставить
   реальную панель с отверстиями: на U1 квадратная площадка — вывод 1,
   маркировка `1` со стрелкой указывает верхнюю сторону корпуса. Сначала
   проверить посадку без пайки. PLCC-68 — тип панели, МК — SAB80535-N.
2. Сначала запаять мелкие компоненты с обеих сторон. C10/C11/C12/C13/C14
   и R20…R27 находятся сзади. Проверить FT232RL и USB-C под увеличением:
   мостики между соседними выводами недопустимы.
3. Установить панели, кварц, кнопку и разъёмы. Ориентировать U3/U4 по
   выемке и квадратной площадке 1; D2/D3 — катод к `K`. Первый вывод
   микросхем SOIC/SSOP обозначен штатной меткой на корпусе и плате.
4. Пока оставить **U1, U3, U4 вынутыми**, JP1 открытым. JP2 можно замкнуть.
   Не подключать периферию к GPIO/AN/BUS. Проверить отсутствие устойчивого
   короткого замыкания VBUS/GND, +5V_USB/GND и +5V/GND; заряд конденсаторов
   может кратковременно выглядеть как малое сопротивление.

## Первое USB-включение и FT_PROG

JP1 изначально **НЕ установлен**. Это исключает запуск потребляющего до
210 мА МК до настройки разрешённого USB-тока.

1. Подключить USB. Измерять относительно TP1 (GND). На TP2 должна быть
   шина +5V_USB, близкая к 5 В. На TP3 основная +5V должна быть выключена.
   Если TP3 уже питается, проверить JP1, EN# U6 и отсутствие мостиков.
2. Должен обнаружиться FT232R. Открыть FT_PROG, считать EEPROM и сохранить
   резервную копию настроек. В USB Config выбрать bus-powered, Max Power
   **500 mA**; CBUS3 назначить **PWREN#**; включить **Pull Down on Suspend**.
   Записать и повторно считать для проверки. VID/PID не менять произвольно.
3. Отключить USB. Установить JP1, подключить снова. После enumeration TP3
   должен получить питание и D2 загореться. В suspend основная шина
   отключается, данные SRAM теряются — это предусмотренное поведение.
4. На TP3 должно быть **более 4,75 В под нагрузкой**, но не выше 5,5 В.
   MCP120-475 может удерживать RESET# при меньшем напряжении. Кабель,
   предохранитель, феррит и ключ дают падение напряжения: запуск от любого
   USB-порта не гарантируется. Использовать короткий кабель и хороший
   питаемый хаб. Не перемыкать супервизор и не подавать второе питание
   параллельно USB. Источник USB должен оставаться в штатном диапазоне 5 В.
5. TP4/RESET# после задержки супервизора должен подняться, при RESET —
   опуститься почти до GND. Нормальный гарантированный высокий уровень
   входа RESET МК — не менее 3 В. TP10/OC# — высокий, кроме короткого
   переходного состояния; устойчивый низкий означает перегрузку/нагрев U6.

## Первая прошивка и каждое последующее обновление

У SAB80535-N **нет внутренней памяти программ и готового ROM-загрузчика**.
После сброса он читает внешний CODE с адреса 0000h. Предварительно записанный
UART-монитор в этой версии не используется; собственный загрузчик отсутствует.
WE# U3 аппаратно на +5V, поэтому прошивка через установленный UART невозможна.

1. Полностью отключить USB и всё внешнее оборудование. Убедиться, что TP2 и
   TP3 разряжены до 0 В. Снять U3 с панели; не подключать программатор к J7.
2. В программаторе выбрать точный SST39SF010A. Выполнить ID/blank check,
   erase, program и **verify всего файла**
   `firmware/build/retro535-sst39sf010a-128k.bin` (131072 байта).
   Начальный адрес — 00000h, без смещения. Верхние 64 КиБ заполнены FF.
3. Проверить SHA-256 по `firmware/build/SHA256SUMS`. Файл
   `retro535-code64k.bin` — только доступный МК банк; полный 128-КиБ образ
   предпочтительнее, чтобы не зависеть от настройки заполнения программатора.
4. При отключённом питании вернуть U3 правильной стороной. Установить
   SRAM U4 и SAB80535-N U1, совместив метку 1 МК с меткой панели/платы.
   Никогда не извлекать PLCC или Flash под напряжением.
5. Подключить USB, открыть COM-порт **9600, 8N1, flow control none**, затем
   нажать RESET. Ожидается сообщение `retro535 v1.0 | SAB80535-N | 9600 8N1`,
   после полного теста — `SRAM PASS 32768 bytes`. D3 меняет состояние
   примерно каждые 500 мс (полный период около секунды).
6. При ошибке выводится первый адрес, ожидаемое и прочитанное значения;
   D3 переключается примерно каждые 100 мс. Тест разрушает **всю** SRAM.

Программирование снятой U3 физически отделяет её от CPU, защёлки, SRAM и
UART. Конфликта драйверов шины при этой процедуре нет. Держать CPU в RESET
и одновременно программировать установленную Flash не является допустимым
режимом v1.0: аппаратного арбитража/разъёма программирования здесь нет.

## Контрольные точки

| Точка | Сигнал | Проверка |
|---|---|---|
| TP1 | GND | Общая точка измерений |
| TP2 | +5V_USB | Питание USB-узла до включения основной части |
| TP3 | +5V | >4,75 В под нагрузкой, D2 горит после enumeration |
| TP4 | RESET# | Низкий при кнопке/запуске, высокий после выдержки |
| TP5 | ALE | Импульсы защёлки адреса при работающем МК |
| TP6 | PSEN# | Импульсы чтения CODE |
| TP7 | RD# | Импульсы во время чтений SRAM |
| TP8 | WR# | Импульсы во время записей SRAM |
| TP9 | AVREF | Близко к +5V, немного ниже из-за R8; не вход питания |
| TP10 | OC# | Высокий в норме, низкий при перегрузке U6 |

Для генератора лучше измерять XTAL2 щупом с малой ёмкостью; сам щуп может
влиять на запуск и частоту. Ожидается 11,0592 МГц. VBB=U1.37 — внутреннее
смещение: не подавать туда питание, не замыкать на землю; только C12.
J7 нагружать лишь высокоомным щупом, без длинных шлейфов. Все GPIO/AN
подключать только после стабильного SRAM PASS. Внешнюю нагрузку +5V
ограничить 50 мА до фактического измерения общего бюджета.

Если нет UART: проверить TP3/TP4, ориентацию U1/U3, содержимое Flash,
EA#=0, наличие ALE/PSEN#, JP2, настройки COM-порта. Если нет питания после
enumeration — FT_PROG/JP1/PWREN#/OC#. Не менять номиналы или перемыкать
защиту до измерений.
